# Auto Truck · Análise de Divergências

Build compilado da tela de análise de divergências (boletim de ocorrência × declaração do associado), publicado pelo GitHub Pages.

O acesso exige login de administrador da Auto Truck. Os dados ficam no Supabase e só são liberados para usuários com papel de admin.

O código-fonte fica no repositório privado do portal (`npm run build:antifraude`). Este repositório contém apenas os arquivos gerados.
